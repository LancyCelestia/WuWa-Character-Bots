# 术语表（守岸人 bot 主包）

> 只做一件事：钉死**同一个词在本仓被当成两三种意思**的那些。
> 不收录「一看就懂」的词，也不收录代码里已有唯一真身的名字——那些直接读代码。
> 每条形如：**词** ＝ 本仓唯一含义（其余说法一律是另一个词）。
>
> 本文件是词条的**唯一真身**。根目录 `GLOSSARY-MAP.md` 指向它。
> 归属登记在 `docs/boards/_meta/doc-classification-20260921.md`。

## 一、调度与出口

| 词 | 本仓唯一含义 | 不是 |
|---|---|---|
| **中央调度缝** | `RuntimePipeline` 那一段：能力结果 → review → renderer → send_queue → sender 的**唯一出口** | 不是「路由」；路由只决定进哪个能力 |
| **出站咽喉** | `domains/transport/sender/` 下统一打码与统一投递的那一处 | 不是「发送函数」；任何直接调平台的调用都不算 |
| **旁路腿** | 绕过中央出口、自己把消息送出去的那条路 | 不是「另一条出口」——它是**缺陷形态**，不是设计 |
| **主动推送** | 只准走 `submit_active_push` 的投递 | 不是「定时任务」；定时只是触发源 |
| **能力（capability）** | 一个占 `RouteKind` 席位、有 `capability_id` 的处理单元 | 不是「函数」；一个能力可以有多个函数 |

## 二、登记与生效

这三个词经常被混成一句「已经做了」，实际是三件不同的事：

| 词 | 本仓唯一含义 | 判据 |
|---|---|---|
| **在册** | 名字出现在某张登记表里（`ROUTE_CAPABILITY_DECLARATIONS`、`_HELP_ENTRIES`、`RESTART_REQUIRED_KEYS`…） | 只在表里查得到，**不代表有人调用** |
| **接线** | 真的有一个生产调用点指向它 | 有调用点，**不代表有门禁在管** |
| **已执法** | 有一条机器门会在它被违反时变红 | 只有测试红，才算执法 |

> **在册 ≠ 接线 ≠ 已执法。** 任何「已完成」的宣称必须指明落在哪一格；
> 只说「已登记」而说不清另两格的，按未完成记账。

| 词 | 本仓唯一含义 | 不是 |
|---|---|---|
| **待生效** | 代码已改，但进程没重启，线上行为还是旧的 | 不是「已完成」；本仓铁律：改代码必须重启 bot 才生效 |
| **已生效** | 进程已带新代码跑起来，且有实跑读数 | 不是「提交了」 |
| **热更** | 不重启就改行为的键（进 `SETTABLE_KEYS` 且消费点现读） | 不是「改了 `.env` 就生效」——消费点读的是装配期快照时，热改是假的 |
| **装配期快照** | 进程启动时读进闭包的那份 config，之后不再变 | 不是「当前配置」 |
| **死开关** | 写进去能成功、行为一点不变的开关（C-09 明令禁止） | 不是「默认关闭的功能」——默认关是设计，死开关是欺骗 |

## 三、证据

| 词 | 本仓唯一含义 | 不是 |
|---|---|---|
| **真身** | 某逻辑唯一允许存在的那份实现 | 不是「最新那份」；垫片、副本都不是真身 |
| **垫片（shim）** | `Compat shim` 头注 + PEP 562 `__getattr__` 的再导出文件 | 不是实现，**不算文件数、不算接线** |
| **机器册** | `docs/auto-facts.md`，由生成器从代码派生 | 不是人写的文档；手改即错 |
| **存在性锁** | 只断言「文件在 / 符号在」的测试 | **不算修好**——它拦不住行为回退 |
| **注毒** | 故意塞一条违规进去，断言门必红 | 不是「跑一遍绿的就算有牙」 |
| **复跑** | 把命令原样再跑一遍并贴出读数 | 不是「之前跑过」；没给命令与输出的，按未验证记账 |
| **当时值** | 一个曾经正确、现在可能已漂的数 | 不是「当前值」；看到它就要去真身现算 |
| **口径** | 这个数是怎么数出来的（扫描面 + 过滤条件 + 时刻） | 不是「大概」；没有口径的数不可引用 |

## 四、视觉

| 词 | 本仓唯一含义 | 不是 |
|---|---|---|
| **token** | `theme_tokens.py` 里登记的颜色/尺寸常量 | 不是「样式变量」的泛称；表外值一票否决 |
| **accent** | 平台色的唯一受控出场之一（徽章/高亮/链接） | 不是底色；`--accent` 永不做底色 |
| **壳底（shell wash）** | `SHELL_WASH_GRADIENT` 那一条多色交织渐变 | 不是「背景色」；手抄第二份＝漂移源 |
| **渲染面** | 一个会产出卡片/HTML 的出口（Jinja 模板或 f-string 直拼卡） | 不是「页面」 |
| **契约** | `docs/rendering-contract.md` 的七条铁律 + 断言位置列 | 不是「约定」；叙述与断言冲突时以断言为准 |

## 五、运维

| 词 | 本仓唯一含义 | 不是 |
|---|---|---|
| **重启** | 停进程 → 起进程，让新代码生效 | 不是「热更」；也不是「重连」 |
| **健康** | 四项就绪度实测通过 | 不是「进程活着」 |
| **静默失败** | 出错但不报、不记、不告警，看起来一切正常 | 不是「降级」；降级有显式出口 |
| **兜底** | 主路失败后明确走的那条替代路 | 不是「吞异常」 |
| **生产库** | `ChatBot_Runtime/` 下的 SQLite | 不是 `data/`；源码树出现 `data/` 是事故 |
