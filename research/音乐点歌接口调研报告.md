# 聊天机器人「音乐点歌」功能 — 技术选型调研报告

> 调研时间：2026-08（文中所有「实测」均来自本机实时请求验证；「时效」以检索到的公开资料与实测结果交叉为准）
> 调研对象：网易云音乐、QQ 音乐、酷我音乐、酷狗音乐、Spotify、Apple Music
> 使用场景：AstrBot / NoneBot / dify-on-wechat 等聊天机器人的点歌命令（搜索 → 选歌 → 输出语音/卡片/文本+链接）

---

## 0. 结论速览（TL;DR）

| 平台 | 搜索（免登录） | 音频 URL（免登录） | 结论 |
|---|---|---|---|
| **网易云音乐** | ✅ 可用 | ⚠️ 免费曲可用，VIP 曲返回试听/null | **主推音源**（自建 Node API 或直连旧接口） |
| **Apple Music (iTunes)** | ✅ 可用（无 key） | ✅ 30s previewUrl 稳定 | **海外曲目主推**，纯公开无任何鉴权 |
| **QQ 音乐** | ✅ 可用 | ⚠️ 匿名 vkey 已收紧（实测返回空 purl） | 卡片模式（CQ:music）可做；直链靠第三方聚合 |
| **酷狗音乐** | ✅ 可用 | ❌ 匿名直链被反爬拦截（实测 url 为空） | 搜索可做，直链降级为第三方 |
| **酷我音乐** | ❌ 需 JS 生成的 csrf token | ❌ 旧接口已 404 | 全部降级为第三方聚合 |
| **Spotify** | ✅ 官方 Web API（需注册 App 拿 client id） | ⚠️ preview_url 大量为 null（2024-11 起收紧） | 只做「信息卡 + 跳转链接」；大陆需代理 |

**推荐方案**：
1. **可播放音源优先**：网易云（自建 `api-enhanced`/NCM API fork，搜索/详情/封面全免费，音频 URL 免费曲可用、VIP 曲自动降级试听）+ Apple iTunes Search（纯公开、无 key、返回 30s previewUrl，海外曲目命中率高）。
2. **卡片优先的国内平台**：QQ 音乐用 `[CQ:music,type=qq,id=xxx]` 卡片（go-cqhttp/NapCat 服务端渲染，**完全不需要音频 URL**）；或在需要直链时接 `music.txqq.pro` 聚合。
3. **信息卡 + 跳转链接降级**：Spotify（oEmbed/Web API 拿信息 → 跳转 `open.spotify.com`）、酷我/酷狗（搜索可用 → 跳官网/分享链接）。
4. **通用兜底**：输出模式按 `卡片 → 语音链接 → 本地语音 → 文本链接` 自动降级（AstrBot 生态现成范式）。

## 1. 网易云音乐

### 1.1 重要背景：原版 NeteaseCloudMusicApi 已于 2024-01 停止维护

Binaryify/NeteaseCloudMusicApi（曾 3 万+ star）在 [2024-01 收到网易法律通知后仓库被清空](https://www.landiannews.com/archives/101953.html)，原 README 现仅剩「保护版权，此仓库不再维护」。**现役替代品**：

- [neteasecloudmusicapienhanced/api-enhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced)（原名 SunsetMkt/ncm-api-enhanced，v4.40+，半重构增强版，Docker 部署）——AstrBot 官方点歌插件依赖它
- [Catamint/ncm-api-enhanced](https://github.com/Catamint/ncm-api-enhanced)、`@neteaseapireborn/api` 等 fork
- 公共实例（社区分享，**稳定性无法保证**，实测本机全部连不上）：`https://163api.qijieya.cn`、`https://zm.armoe.cn`、`http://dg-t.cn:3000`、`https://wyy.xhily.com`、`https://music-api.focalors.ltd` 等（可用 `allinurl:eapi_decrypt.html` 搜索）

### 1.2 公开接口（自建 Node API 形态，即 NCM API 的 HTTP 封装）

原理：CSRF + 伪造请求头调用官方 `weapi/eapi`，服务端做 AES/RSA 加密。

**搜索（无需登录）**
```
GET http://localhost:3000/search?keywords=晴天&limit=30&offset=0
GET http://localhost:3000/cloudsearch?keywords=晴天&limit=30   # cloudsearch 结果更全
# 可选参数：type=1(单曲,默认) 10=专辑 100=歌手 1000=歌单 1004=MV ...
```
返回 `result.songs[]`：`id`、`name`、`ar[].name`（歌手）、`al.picUrl`（封面）、`al.name`（专辑）、`dt`（时长）、`fee`（0=免费 1=VIP 8=试听）。

**获取音频 URL（关键）**
```
GET http://localhost:3000/song/url?id=33894312&br=320000
# 官方文档原话：未登录状态或非会员返回试听片段（返回字段含截取开始/结束时间）
# Vercel 部署需附加 realIP：/song/url?id=191254&realIP=116.25.146.177
```
- 匿名/非会员：**免费歌曲返回完整 URL，VIP 歌曲返回试听片段或 null**。实测（2026-08）免费歌曲仍可匿名取直链，VIP 曲（如周杰伦）返回 null。
- **防盗链 403 兜底**：文档给出的官方解法——把 `https://music.163.com/song/media/outer/url?id={id}.mp3` 直接作为 `<audio src>`（实测返回 200，可播放；服务端 302 到真实 CDN）。
- 版权检查：`GET /check/music?id=xxx` 返回 `{success:true}` 或 `{success:false,message:'亲爱的,暂无版权'}`。

**其他**：`GET /song/detail?ids=xxx`（详情+封面）、`GET /lyric?id=xxx`（歌词）。

### 1.3 直连官方旧接口（无需自建，实测可用）

```
GET https://music.163.com/api/search/get/web?s=晴天&type=1&limit=3&offset=0
# 需带 UA + Referer: http://music.163.com（实测 200，songCount=336）
```
- 老接口无需加密、免登录，AstrBot 插件 `astrbot_plugin_m`、`astrbot_plugin_music`（网易模块）、NoneBot `simplemusic` 均直接用它做搜索。
- 注意：实测该接口**结果排序与官网不同**（"晴天" 前排是翻唱版），且拿不到 mp3url，只能拿 id → 仍需 Node API 或第三方接口取播放链接。
- 热评（weapi，需预加密 params/encSecKey，可用硬编码固定值）：`POST https://music.163.com/weapi/v1/resource/hotcomments/R_SO_4_{song_id}?csrf_token=`。

**要点小结**：搜索/详情/封面免登录零成本；音频 URL 免费曲可直接拿，VIP 曲返回试听片段/null，需要 cookie（登录）才可解锁；无 IP 限制、无地域限制，大陆直连顺畅。

## 2. QQ 音乐

### 2.1 搜索接口（免登录，实测可用）

**方式 A：老牌 JSONP 接口（simplemusic 等插件在用，实测 200）**
```
GET https://c.y.qq.com/soso/fcgi-bin/client_search_cp?w=晴天&format=json&p=1&n=10&aggr=1&cr=1&lossless=1&new_json=1
# 需 UA + Referer: https://y.qq.com/
# 返回 data.song.list[]：songmid（关键）、songname、singer[].name、albumname、albummid、interval(秒)
```

**方式 B：新版聚合接口（copws/qq-music-api 2025.9 验证可用，实测 200）**
```
POST https://u.y.qq.com/cgi-bin/musicu.fcg
Content-Type: application/json;charset=UTF-8
Body: {"comm":{"ct":"19","cv":"1859","uin":"0"},
       "req":{"method":"DoSearchForQQMusicDesktop","module":"music.search.SearchCgiService",
              "param":{"grp":1,"num_per_page":10,"page_num":1,"query":"晴天","search_type":0}}}
# 实测需带 UA + Referer: https://y.qq.com/（否则返回 code=2001 空列表）
# 返回 req.data.body.song.list[]：mid / name / singer[].name / album.mid / interval
```

**方式 C：搜索建议（智能提示，免登录，实测 200）**
```
GET https://c.y.qq.com/splcloud/fcgi-bin/smartbox_new.fcg?key=晴天&format=json
# 返回 album/song 的 mid、name、pic、singer
```

### 2.2 音频 URL 接口（⚠️ 匿名已收紧）

```
POST https://u.y.qq.com/cgi-bin/musicu.fcg
Body: {"req_1":{"module":"vkey.GetVkeyServer","method":"CgiGetVkey",
        "param":{"filename":["M800{songmid}.mp3"],"guid":"10000","songmid":["{songmid}"],
                 "songtype":[0],"uin":"0","loginflag":1,"platform":"20"}},
       "loginUin":"0","comm":{"uin":"0","format":"json","ct":24,"cv":0}}
# 返回 req_1.data.sip[0] + midurlinfo[0].purl 拼接即直链
# M500=128k mp3 / M800=320k mp3 / C400=m4a
```
- copws 文档标注 2025.9 验证可用（guid 写死 `10000`、uin 写死 `0` 即可）。
- **实测（2026-08）**：所有测试歌曲（含儿歌、免费歌）`purl` 均返回空，`midurlinfo[0].result=104003`——匿名 vkey 已被收紧（疑按 IP/风控，需登录 cookie `uin`+`qqmusic_key`，或大陆住宅 IP）。**结论：直连方案不可靠，需降级。**
- 反爬点：`Referer: https://y.qq.com/` 必需；guid/uin 非必填登录但影响出链；VIP 曲即使出链也只有试听。

### 2.3 现成可靠路径（实测验证）

- **CQ:music 音乐卡片**：`[CQ:music,type=qq,id={songid}]`（onebot v11 协议），go-cqhttp/NapCat 服务端自行渲染分享卡片，**完全不需要音频 URL**。仅需方式 A/B 拿到 `songid`（或 `mid`）。QQ 生态内体验最好。
- **第三方聚合 `music.txqq.pro`（AstrBot 插件 astrbot_plugin_music 在用，实测可用）**：
```
POST https://music.txqq.pro/
Content-Type: application/x-www-form-urlencoded
Body: input=晴天&filter=name&type=qq&page=1
（需 UA + Origin/Referer: https://music.txqq.pro + X-Requested-With: XMLHttpRequest）
返回 {"code":200,"data":[{title, author, url(直链含vkey), pic(封面), lrc, songid}]}
```
实测返回的 `http://aqqmusic.tc.qq.com/C400xxxx.m4a?guid=...&vkey=...&uin=&fromtag=120032` **可播放（HEAD 200, audio/mp4）**。支持 type=qq/kugou/kuwo/baidu/1ting/migu/lizhi/qingting/ximalaya/5sing/kg 等。免费曲返回免费版本（VIP 曲自动返回可免费听的翻唱/片段）。
- 其他第三方：`https://api.suyanw.cn/api/kw.php?msg=晴天`（酷我文本列表，实测可用）、`https://www.hhlqilongzhu.cn/api/dg_kgmusic.php?gm=...&n=...` 等（2026-08 实测不可达，作为备选列出）。

## 3. 酷我音乐（Kuwo）

### 3.1 搜索接口
```
GET https://www.kuwo.cn/api/www/search/searchMusicBykeyWord?key=晴天&pn=1&rn=30
# 曾用的简化参数：key/pn/rn；响应 data.list[]：rid(音乐ID)/name/artist/album/pic
```
- **实测（2026-08）**：匿名直接请求返回 `403` 或 `{"success":false,"message":"The request is illegal!"}`。
- 反爬机制：需 `kw_token` cookie + 请求头 `csrf`（两值一致）+ 合法 `Referer` + 特定 UA；token 由页面 JS 生成，纯 requests 拿不到（实测访问首页/搜索页均未下发 cookie）。**直连基本废弃**。

### 3.2 音频 URL 接口
```
GET https://www.kuwo.cn/url?format=mp3&rid={rid}&response=url&type=convert_url3&br=128kmp3&from=web&t={ts}&reqId={uuid}
# 历史接口（kuwo_cn 项目 2020 年文档）：曾返回 {"code":200,"url":"https://sz-sycdn.kuwo.cn/....mp3"}，几乎无反爬
```
- **实测（2026-08）**：该 URL 接口已 **404**（下线）。当前酷我直链需 App 端签名（`type=convert_url3` 链已废弃）。

### 3.3 可行路径
- 第三方聚合：`music.txqq.pro`（type=kuwo，实测 code=200 返回结果）、`https://api.suyanw.cn/api/kw.php?msg=晴天`（实测可用，返回 "1：晴天——周杰伦 2：…" 文本列表，配合 `&n=序号` 出直链）、`https://hhlqilongzhu.cn/api/dg_kuwomusic.php?msg=...&n=...`。
- 结论：**酷我只做「搜索信息 + 第三方直链」降级**，官方接口不可直连。

## 4. 酷狗音乐（Kugou）

### 4.1 搜索接口（免登录，实测可用）
```
# 方式 A（实测 200，推荐）
GET http://msearchcdn.kugou.com/api/v3/search/song?&plat=0&keyword=晴天&tagtype=全部&pagesize=10&version=9108
# 返回 data.info[]：hash(关键)/songname/singername/album_name/album_id/duration/pay_type
#   封面: https://imge.kugou.com/stdmusic/{album_id}.jpg

# 方式 B（mobilecdn，2024-12 社区验证可用）
GET http://mobilecdn.kugou.com/api/v3/search/song?format=json&keyword=晴天&page=1&pagesize=10

# 方式 C（实测 200）
GET http://songsearch.kugou.com/song_search_v2?keyword=晴天&platform=WebFilter&format=json&page=1&pagesize=10
# 返回 data.lists[]：FileHash/FileHash320/SongName/SingerName/AlbumID/FileDuration
```
注意：`mobilecdn.kugou.com` 的 HTTPS 证书链对部分客户端不友好（实测 TLS 握手失败），`msearchcdn`/`song_search_v2` 用 HTTP 即可。

### 4.2 音频 URL 接口（⚠️ 匿名被反爬）
```
# 方式 A（2024-12 社区标注可用）
GET http://m.kugou.com/app/i/getSongInfo.php?cmd=playInfo&hash={hash}
# 方式 B（keyule/KuGou-API 文档）
GET https://wwwapi.kugou.com/yy/index.php?r=play/getdata&callback=jQuery...&mid=1&hash={hash}&album_id={album_id}
# 均返回 url/play_url + 封面 + 歌词
```
- **实测（2026-08）**：两者匿名请求均只返回元数据而 **url 为空**（`getdata` 直接返回 `err_code:30020` + `SSA-CODE` 风控标记，`playInfo` 返回 `status=0` 但 url 为空）。酷狗已启用设备指纹（dfid/SSA）类反爬，**匿名直链不可用**。
- 社区项目 [MakcRe/KuGouMusicApi](https://github.com/MakcRe/KuGouMusicApi)（CSRF 伪造 + 登录 + Vercel 一键部署）可维护性取决于酷狗改版节奏，需常更新；概念版（platform=lite）需专属 token。
- **可行路径**：`music.txqq.pro`（type=kugou，实测接口可达）、`https://www.hhlqilongzhu.cn/api/dg_kgmusic.php?gm=...&n=...`（dify-on-wechat SearchMusic 插件在用）。结论：**酷狗搜索免费可直连，音频 URL 走第三方降级**。

## 5. Spotify

### 5.1 官方 Web API（[developer.spotify.com](https://developer.spotify.com/documentation/web-api)）
```
# 1) 获取 token（Client Credentials 流，免费，无需用户授权）
POST https://accounts.spotify.com/api/token
Authorization: Basic base64(client_id:client_secret)
Body: grant_type=client_credentials
# 2) 搜索（返回 track：id/name/artists/album/images/preview_url/external_urls.spotify）
GET https://api.spotify.com/v1/search?q=晴天&type=track&limit=10&market=CN
Authorization: Bearer {token}
```
- 注册开发者 App 免费（developer.spotify.com/dashboard），client credentials 模式无需用户登录。
- **30 秒试听 preview_url 可用性（关键变化）**：官方在 [2024-11-27 Web API 变更公告](https://developer.spotify.com/blog/2024-11-27-changes-to-the-web-api) 中**将 30 秒 preview URL 从 multi-get 响应（SimpleTrack）中移除**；新注册/开发模式未扩展的应用，`preview_url` 大量返回 `null`（[社区大量反馈](https://stackoverflow.com/questions/79237053/android-spotify-api-preview-url-for-tracks-is-suddenly-being-returned-as-null)）。**不能依赖 preview_url 作为稳定音源。**

### 5.2 Embed / oEmbed（无需 token）
```
GET https://open.spotify.com/oembed?url=https://open.spotify.com/track/{id}
# 返回 {"html":"<iframe src=\"https://open.spotify.com/embed/track/{id}?utm_source=oembed\" ...>"}
```
- oEmbed 免鉴权、返回可直接嵌入的 iframe 播放器 HTML（[官方 oEmbed 文档](https://developer.spotify.com/documentation/embeds/reference/oembed)）。
- **大陆直连性**：`api.spotify.com` / `open.spotify.com` / `p.scdn.co` 在大陆**被墙，需代理**（见 [Clash 分流 Spotify 域](https://clashsurge.com/zh-TW/blog/articles/clash-spotify-domain-split-rules-region-nodes-streaming-2026.html)、[spotDL 代理方案](https://blog.gitcode.com/22ce16b4b1bbd6f0d8fbf37e2d08fc2e.html)）。

**结论**：Spotify 适合「信息卡 + 跳转 `open.spotify.com/track/{id}` / oEmbed iframe」降级；作为可播放音源不可靠（preview 收紧 + 大陆墙）。若服务器/用户环境可科学上网，Client Credentials 搜索本身是免费的。

## 6. Apple Music（iTunes Search API）

### 6.1 完全公开、无需任何 key（实测可用）
```
GET https://itunes.apple.com/search?term=晴天&country=cn&media=music&entity=song&limit=10
```
- 参数：`term`（关键词，URL 编码）、`country`（商店国家/地区，如 cn/us/jp，默认 us；**曲库不同**）、`media=music`（必须）、`entity=song`（限定单曲）、`limit`（1-200）、`offset`。
- 更多：`attribute=songTerm`（限定匹配歌名）、`lang=zh_cn`；单曲详情用 `https://itunes.apple.com/lookup?id={trackId}&country=cn`。
- 返回 `results[]` 关键字段：`trackId`、`trackName`、`artistName`、`collectionName`（专辑）、`artworkUrl100`（封面，可把 `100x100` 换成 `300x300`/`600x600` 拿大图）、`previewUrl`、`trackViewUrl`、`trackTimeMillis`、`releaseDate`。

### 6.2 试听 previewUrl（实测可用）
```
GET https://itunes.apple.com/search?term=晴天&country=cn&media=music&entity=song&limit=2
# 实测返回：
#   "previewUrl": "https://audio-ssl.itunes.apple.com/itunes-assets/AudioPreview221/v4/....m4a"  ← 30 秒 AAC/m4a 试听，直链可播放
#   "trackViewUrl": "https://music.apple.com/cn/album/晴天/535824731?i=535824738&uo=4"
```
- 30 秒试听为 **AAC .m4a**，无 referer/防盗链（实测可访问）。**这是全调研中唯一「无 key + 免登录 + 稳定可播放试听」的官方源。**
- 缺点：曲库 = Apple 各地区商店授权，**中文老歌/港台曲命中率受 `country` 影响**（cn 商店有周杰伦等，但部分平台独占曲缺失）；只有 30s 试听，无整曲。
- **大陆直连性**：`itunes.apple.com` 与 `audio-ssl.itunes.apple.com` 走 Apple 全球 CDN，**大陆可直连**（实测 200；社区亦确认 [iTunes Search API 可直连](https://public-api.org/zh/api/900/itunes-search)）。注意：`music.apple.com` 网页播放与 Apple Music 服务（api.music.apple.com，需开发者 key）在大陆受限，但**搜索/试听接口不受影响**。

## 7. 点歌插件生态调研（AstrBot / NoneBot）

### 7.1 AstrBot 生态（输出范式最完整）
| 插件 | 后端 | 输出方式 | 备注 |
|---|---|---|---|
| [astrbot_plugin_music (Zhalslar)](https://github.com/Zhalslar/astrbot_plugin_music) | 网易 NodeJS API（公共实例或自建 Docker `binaryify/netease_cloud_music_api`）+ **txqq.pro 聚合**（QQ/酷狗/酷我/百度/咪咕/喜马拉雅等） | 发送策略 `card(QQ+网易云卡片) → record_link(CQ record URL) → record_local(下载后发本地语音) → file_link → file_local → text(链接)` 自动降级；选歌支持 button/text/image/single | **推荐直接参考其 sender.py 降级链** |

### 7.3 模式总结
- **输出三范式**：(a) CQ 音乐卡片 `[CQ:music,type=qq/163,id=xxx]`（最稳，无需音频 URL，go-cqhttp/NapCat 渲染）；(b) 语音 `[CQ:record,url=...]`（需直链，QQ 内可点播）；(c) 文本/图文卡片 + 跳转链接（全平台通用兜底）。
- **后端选择共识**：网易 = 自建 Node API 最稳（公共实例不稳定）；QQ = 卡片优先 / 聚合站直链；酷我酷狗 = 官方只做搜索，直链全靠第三方聚合；Spotify/Apple = 信息卡 + 跳转。

## 9. 特别注意事项（反爬与时效）

1. **QQ vkey 时效性最强**：匿名 `guid=10000&uin=0` 方案 2025.9 尚可用（copws 合集标注），2026-08 实测已返回空 purl（result=104003）。**任何直链方案都要做「失败→卡片/链接降级」**。
2. **网易原版 API 已停维护**：不要再依赖 Binaryify 仓库及其 Docker 镜像 tag，用 [api-enhanced](https://github.com/neteasecloudmusicapienhanced/api-enhanced)（v4.40+）或 sssnan 备份 fork；公共实例多为个人维护，随时可能失效。
3. **酷我 csrf / 酷狗 SSA 风控**：都是「先取页面/设备指纹 → 再带签名请求」的链路，纯脚本难模拟；**建议官方接口只用于搜索，URL 一律走第三方聚合**（txqq.pro / suyanw / hhlqilongzhu，注意聚合站本身也可能失效，需配置多个 + 健康检查）。
4. **Referer/UA 是基本盘**：QQ（y.qq.com）、网易（music.163.com）、酷我（www.kuwo.cn）的接口对 UA+Referer 敏感，缺省会触发 403/风控返回。
5. **Spotify preview_url 不要当音源**：新 App 已拿不到；即使拿到也是 30s。大陆用户端连 `open.spotify.com` 都打不开，卡片里的图/试听同样不可用——**除非机器人服务端代理，否则 Spotify 只能输出纯文本信息**。
6. **Apple iTunes 试听是 AAC m4a**：QQ 语音（CQ:record）对格式要求宽松（NapCat/go-cqhttp 会转码），但微信等平台对 m4a 支持不一；建议服务端先转 mp3 再发，或直接发链接让客户端播。
7. **版权风险**：以上接口多为未公开/逆向接口，仅限个人学习与内部机器人使用，勿商用、勿对外大规模提供下载解析（网易 2024 清库即前车之鉴）。

## 10. 推荐落地方案

**一级音源（可播放，优先）**
1. **网易云**：Docker 自建 `api-enhanced`（`neteasecloudmusicapienhanced/api-enhanced`）→ `/cloudsearch`（搜索+详情+封面）→ `/song/url?id=`（免费曲直链、VIP 自动试听）→ `/lyric`、`/comment/hot`（附加内容）。
2. **Apple iTunes**：`itunes.apple.com/search?term=..&country=cn&media=music&entity=song` → `previewUrl` 作 30s 试听直链、`artworkUrl100` 作封面、`trackViewUrl` 作跳转。海外/欧美曲目优先用它。

**二级（卡片/直链混合）**
3. **QQ 音乐**：搜索用 `client_search_cp` 或 `musicu.fcg`；QQ 渠道直接发 `[CQ:music,type=qq,id={songid}]` 卡片（零直链成本）；非 QQ 渠道需要直链时走 `music.txqq.pro`（type=qq），失败降级文本+`https://y.qq.com/n/ryqq/songDetail/{mid}` 链接。

**三级（信息卡 + 跳转链接降级）**
4. **Spotify**：Client Credentials 搜索 → 输出 `歌曲名 - 歌手` + `https://open.spotify.com/track/{id}`（有条件时附 oEmbed iframe）；大陆环境只输出文本链接。
5. **酷狗/酷我**：官方搜索接口（酷狗 3 选 1）拿信息 → 直链走 `music.txqq.pro`/`api.suyanw.cn`，失败输出官网搜索链接 `https://www.kugou.com/yy/index.php?key=..` / `https://www.kuwo.cn/search/list?key=..`。

**输出顺序（参照 astrbot_plugin_music）**：`卡片 → record_link → record_local → file → text`，每级失败自动降级；同时保留「搜到列表 → 用户选序号」的交互。

**附带成本**：仅需自建网易 Node API（一台小内存服务器/Docker）+ 可选第三方聚合站 2-3 个做冗余；其余全部零成本免 key。
