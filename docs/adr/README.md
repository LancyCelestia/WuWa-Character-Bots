## 什么算一条 ADR

- **算**：推翻一条已在册的规范 / 改变某类文件的落位约定 / 决定某件事不做且要留痕。
- **不算**：修 bug、加功能、改参数。那些进 `docs/HANDBOOK.md` 与已知问题台账，不进这里。
