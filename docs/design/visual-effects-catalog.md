## 0. 前置分析（三条设计公理，先读）

### 0.1 输出媒介是静态 PNG——动画价值的物理上限

QQ 侧收到的是 playwright 对 `.card` 元素的截图 PNG（`omit_background` 出圆角卡）。**终端用户永远看不到任何 CSS 动画的「过程」，只看得到被定格的那一帧。**

- **推论 1**：一切「动起来」的设计若不以「定格构图好看」为目标，价值为零。
- **推论 2**：动画的风险为负——截图时机按调用点分 0 / 300 / 1500 / 3000ms 四档（管线规格 §1.2）；一击性动画（如 600ms 入场淡入）在 0ms 档（market/fx/stocks/affinity/usage/echo 等直出卡，networkidle 后即截）会被**截在中途**，出半透明鬼影帧。
- **推论 3**：已上线的 `mica-drift` 是正确范式——无限 alternate 循环 + 负 `animation-delay` 随机相位，**任何时刻截都是合法构图**。新特效要么沿用循环范式，要么干脆不做动画、只做静态构图。

与管线规格 P0（信号驱动等待）的交互：`document.fonts.ready` / `img.complete` / 双 rAF 信号对无限循环动画无感知差异，静态与循环特效不干扰 P0；**一击性动画与信号驱动正面冲突**（更早的截帧时机 + 动画未进任何等待信号 = 鬼影概率上升），是 E10 否决的加重项。

### 0.2 截图确定性分级（同一 payload 两次截图是否稳定）

| 级别 | 定义 | 现状/归属 |
|---|---|---|
| **D0 静态确定** | 无动画无随机，同环境两次截图逐像素稳定 | 本目录多数静态候选可达 |
| **D1 相位确定** | 有循环动画，但相位由 payload digest 钉住 | 动版候选（E07 动版）依赖 E01 |
| **D2 随机帧** | （**历史现状=09-13 时点**）drift：`--phase` 由内联脚本 `Math.random()` 每次覆写（`universal_card.html:1688-1694`，六模板同构）。**今：Math.random 内联脚本已从全 7 模板移除（2026-09-20 grep 实测=0），相位由 payload digest 注入 + render_backends WAAPI 钉帧，锁测（test_phase_determinism*）在位** | 「现状全部卡片」为成文时点账，已被 E01 实施取代；现势相位态=上行 D1 |
| **D3 时段相关** | 随渲染时刻变化 | E08 |

两个**免费的确定性开关**（回归测试与生产各用其一）：

1. **测试侧**：playwright `page.emulate_media(reducedMotion="reduce")` → 命中模板既有的 `prefers-reduced-motion` 关停（契约 §五.6 已强制要求）→ 动画全灭、色斑落在无 transform 的静态位 = **确定静态构图，零模板改动**。视觉回归（像素 diff）必须在此模式下跑。
2. **生产侧**：`--phase` 从内联随机改为 **bridge 按 payload 语义 digest 注入**（管线规格 §4.2.2 的缓存键同源思路）→ 同 payload 永远定格同一帧，即 E01。

CSS 之外的残余不确定源（回归基线必须隔离，不归本目录解决）：远程封面图片字节、字体加载时点、Chromium 版本、dsf/viewport。对策沿用 vis1 先例：离线 fixture 图（`build_and_shoot.py` 同口径）+ 固定 1504×1000/dsf=2。相位脚本目前**无契约断言**（`tests/test_rendering_contract.py` grep 仅 keyframes 白名单 ：332-334，已核实），改造不受契约测试阻挡。

### 0.3 契约经济学

- `@keyframes` 白名单仅 `mica-drift-a/b/c`（`tests/test_rendering_contract.py:332-334`）。**任何新动画名 = 契约修订（测试白名单扩展 + reduced-motion 关停补写）→ 需用户裁决**；纯静态特效零契约改动。
- 其余硬约束：阴影永远两枚 token；光晕走渐变且 alpha ≥ 0.05；字重 ≤ 700；wash-mist 打底、`--accent` 只 accent、色斑 `--accent` ≤35%；动画元素 `.card` 子树内；gap 取刻度。
- 因此本目录「CSS-only 优先」的真正含义是**静态 CSS 优先**：惊艳度来自构图与 token 运笔，而非动画；动版一律单独标注契约修订成本并默认靠后。

## 2. 候选详述

### E01 漂移相位策展（确定性定格）——推荐首批

- **视觉效果**：用户可见层面=现状 drift 不变，但每次定格从「随机瞬间」升级为「策展构图」——人工评审选出每模板族最美相位（如 0.30–0.45 区间的色斑对角均衡位），同 payload 永远同一构图；不同 payload 仍各有姿态。
- **实现思路**：bridge 按payload 语义 digest（剥离 `updated_at` 等易变字段，与管线规格 §4.2.2 缓存键同源）计算 `phase = (sha1 % 10000) / 10000`，经 Jinja 注入 `--phase`；内联 `Math.random()` 脚本删除或降级为注入失败时的兜底。可选进阶：digest 哈希映射钳制进人工策展区间（既确定又保证构图下限）。
- **形态**：页面零 JS（删脚本）；bridge/模板各一小改动。
- **成本增量**：≈0ms（色斑层数与绘制面积不变；删一段内联 JS 反而省 ~1ms。估算）。
- **确定性**：D2→**D1**。同 payload 两次生产截图逐像素稳定（外部图片字节除外）；与 P2 渲染缓存语义天然对齐（缓存命中本就冻结相位，本候选把未命中路径也变成确定的）。
- **风险**：低。①同一内容重复解析出图完全相同，「每图随机姿态」的新鲜感损失（低频场景，可接受，需用户认可）；②digest 口径必须与缓存键口径一致，否则出现「缓存内外两种构图」（实现时单点共用函数）；③契约测试虽未断言相位脚本，改动后需跑三件套确认无隐性断言。
- **适用卡型**：全部 Jinja 模板（清单与数以 `docs/rendering-contract.md`／机器册 `docs/auto-facts.md` 为准；一处 bridge 公共通道）。
- **契约影响**：零（无新 keyframes、无新阴影、无 DOM 变化）。
- **为什么排第一**：它是其他一切动版特效（E07 动版/E05 策展版）的**确定性地基**，是视觉回归从「结构断言」升级到「像素 diff」的前置条件，且零成本、零契约风险。

### E02 星尘上升定格（庆祝粒子·静版）——推荐首批

- **视觉效果**：好感度升档/占卜大吉/成就时刻，卡面右侧至标题区升起一束「星尘」——12–24 枚 2–5px 圆点（wash-2 星空紫 / 白 / `--accent-light` 三通道），自下而上渐稀渐淡（alpha 0.06–0.35），如快门定格的星屑上升流。**静态构图本身即庆祝语义**，不需要动画表达。
- **实现思路**：bridge 用 payload digest 作种子伪随机预计算粒子表（x/y/粒径/alpha/色通道），Jinja `for` 循环渲染 `.star-mote` span；定位 `position:absolute` 于 `.card` 内专属容器（`.card` 子树内 ✓）；**零 animation**——不求动态，只求定格构图。密度护栏：≤24 枚、总覆盖面积 ≤ 卡面 8%。
- **形态**：页面零 JS；CSS + Jinja + bridge 少量。
- **成本增量**：+15–50ms（新增 ~24 个小 DOM 节点的布局与一次栅格化；radial-gradient 小圆点绘制廉价。估算）。
- **确定性**：**D0**（摆位由 digest 种子决定，无动画无时间因素）。
- **风险**：中低。①密度失控显脏 → 硬上限写进 bridge；②与 drift 色斑叠色过饱和 → 只用白/紫双通道 + `--accent-light`，禁 `--accent` 直涂；③QQ 图片压缩吃掉低 alpha 粒子 → alpha 下限 0.06（高于铁律 0.05）+ 最小粒径 2px；④人格红线：守岸人语气的庆祝是「星尘」不是「彩带礼花」，禁高饱和彩纸配色。
- **适用卡型**：`affinity_card.html`（升档时刻，模板直加）；占卜大吉/成就（走 universal 解析卡族，需 bridge 增 `celebrate` payload 键，缺省不渲染=其他卡零影响）。
- **契约影响**：零（无动画即无 keyframes 扩展；无新增阴影；元素全在 `.card` 内）。

### E03 字体层级微雕——推荐首批

- **视觉效果**：数字与标签的「印刷级」收口——所有数值列等宽数字（`font-variant-numeric: tabular-nums`，market 表格/finance 大数字/affinity 数值补齐，universal 的 `metric-value/author-stat` 已有）；小标签字距 0.05–0.08em（`summary-tag` 的 0.06em 手法推广到区块小标/页脚署名）；大数字行高收敛 1.0–1.15；数字与单位间细空格；标题引言框 `text-wrap: balance`（两行标题不再孤字悬尾）。
- **实现思路**：纯 CSS 属性补齐，不动 DOM 不动字号体系，字重红线 ≤700 不变。
- **形态**：CSS-only。
- **成本增量**：≈0–5ms（纯文本重排，量级远低于一次图片解码。估算）。
- **确定性**：**D0**。
- **风险**：低。①`text-wrap: balance` 需 Chromium 114+（playwright 内置版本待实测复核，unknown 项）——不支持时静默无效、无副作用；②中文字距 >0.1em 显松 → 上限 0.08em 写死；③等宽数字使数字列略宽 → 逐模板目测收口。
- **适用卡型**：全部 Jinja 模板（清单与数以 `docs/rendering-contract.md`／机器册 `docs/auto-facts.md` 为准）。
- **契约影响**：零。

### E04 星屑微光层——二批

- **视觉效果**：本命「星空紫」资产的低密度铺陈——全卡背景约 30 枚 1–2px 星点（单元素多层 `background-image: radial-gradient(...)` repeating，集中在卡面上半部，越靠下越稀），如云母透出的星屑；与 drift 色斑叠加后呈「云间星点」。
- **实现思路**：单个 `::after` 伪元素（或既有 `.drift-blobs` 内新静态层）承载数层小半径 radial-gradient，**纯静态**；动版（超慢 120s opacity 呼吸）需新 keyframes，不推荐。
- **形态**：CSS-only 静态。
- **成本增量**：+3–12ms（一层全卡渐变栅格化。估算）。
- **确定性**：**D0**。
- **风险**：低。①小卡（song_candidates 980 宽）星点显噪 → 按卡宽缩放粒径或只上 universal/mermaid/affinity；②星点与色斑边缘叠出视觉脏斑 → 星点 alpha ≤0.25 且只出现在色斑低密度区（构图固定可预先目测）。
- **适用卡型**：universal（mica 分支先行）、mermaid、affinity。
- **契约影响**：零（静态版）。

### E05 玻璃光泽扫过·定格版（sheen sweep）——二批

- **视觉效果**：玻璃面板（topbar/标题引言框/摘要块）顶缘一道斜向高光带（105° 线性渐变，白 alpha 0.10→0，宽 18–26%），如玻璃反光的快门瞬间。**动版（高光带扫过全卡）明确不做**：0ms 档截帧必中随机位置=随机脏反光。
- **实现思路**：面板 `::after` 静态渐变高光带，位置两种模式：①**定版**（推荐先行）=每模板一处固定构图位（topbar 右上 1/3），D0；②**策展版**=位置由 digest 相位通道决定（复用 E01 通道），D1，二批再议。
- **形态**：CSS-only 静态。
- **成本增量**：+3–15ms（每面板一层渐变；单卡面板 3–8 个，取中估。估算）。
- **确定性**：定版 **D0** / 策展版 **D1**。
- **风险**：中。①高光带压文字降可读 → 限制在面板上部 1/3 或 padding 空白区，白 alpha 上限 0.12；②与渐变描边（border-box 双背景）视觉打架 → 只上面板顶缘，不绕四边；③逐面板叠加后「反光过剩」→ 每卡至多 2 个面板带光。
- **适用卡型**：universal（topbar/标题引言框）、market/finance 头部、affinity 头部。
- **契约影响**：零（静态渐变非 box-shadow，不触两枚阴影 token 铁律）。

### E06 图片观感统一化（滤镜 token 化）——二批

- **视觉效果**：跨平台封面/banner/专辑图亮度饱和度参差（B 站艳、YT 偏灰）被统一到守岸人观感：`saturate(1.04) contrast(1.02)` 的轻级别 grade，媒体在同一张卡里「同一台相机拍的」。
- **实现思路**：`:root` 增 `--img-grade: saturate(1.04) contrast(1.02)`，应用于 banner 主图 / video cover-contain / 专辑封面；**gallery 原图与头像不加**（原图保真纪律、人脸滤镜风险）；现有 `banner-backdrop` 的 `blur(24px) brightness(.85)` 与 `cover-fill` 的 `blur(22px) saturate(1.08)` 收编为同一对 token 派生。
- **形态**：CSS-only。
- **成本增量**：+8–35ms（filter 按显示尺寸栅格化，单封面量级；多图 gallery 不加故不放大。估算）。
- **确定性**：**D0**（同图同结果）。
- **风险**：中低。①幅度过大显假 → 系数上限 1.05 写死；②低饱和插画被封反而艳俗 → 保留幅度保守起步，bench+目测双验收；③matplotlib 产出的金融走势图**不加**（图表保真优先）。
- **适用卡型**：universal（banner/cover）、song_candidates（专辑封面）。
- **契约影响**：零。

### E07 极光流动背景层——静版二批；动版待裁

- **视觉效果**：wash 色斑之上叠 1–2 条对角狭长光带（星空紫→淡蓝渐变，`mix-blend-mode: screen`，alpha 0.06–0.14），横贯卡面如极光帘；「守岸人的极光」品牌叙事，惊艳度全目录最高。
- **实现思路**：静版=`.card` 子树内静态层（伪元素或 `.drift-blobs` 内新层），渐变一次成型；动版=光带 `translate3d` 超慢循环（60s+ alternate）——**需 keyframes 白名单扩展（契约修订）+ E01 相位钉帧**，且 blend 图层持续合成。
- **形态**：静版 CSS-only；动版 CSS-only 但涉契约修订。
- **成本增量**：静版 +8–25ms（新增一个全卡合成层 + blend 混合）；动版 +20–60ms（transform-only 可走合成器，但 blend 层每帧合成的截前开销仍在。均为估算）。
- **确定性**：静版 **D0**；动版 **D1**（依赖 E01）。
- **风险**：动版中。①契约修订面（新 keyframes 登记 + reduced-motion 关停 + `.card` 子树断言）；②`mix-blend-mode` 与透明截图边界——`.video-card-shell` 已有 `isolation: isolate`（universal:1009），blend 被关在卡内不染透明外区，但其余 5 模板需逐一确认 stacking context（unknown，实施时逐模板核实）；③blend 在低端机 Chromium 的栅格化开销 → bench 实测后再定。静版风险仅剩②。
- **适用卡型**：全卡族背景（分期：universal mica 分支先行）。
- **契约影响**：静版零；动版需修订（白名单 + 关停规则），**先裁决后动手**。

### E08 季节/时段主题微变体——待裁（系统性代价为主）

- **视觉效果**：深夜档（22:00–05:00）wash 四 token 微调——`--wash-mist` 明度 94%→91%、`--wash-2` 星空紫比例 +3%，卡面整体「夜航感」；冬季档紫通道已固定无需动。幅度 ≤5%，色相锚点全部不动。
- **实现思路**：`theme_tokens.derive_wash_tokens` 增可选变体参数（时段档位），bridge 装配期判定注入——模板零改动、纯 Python 单点。
- **形态**：Python 侧（页面仍零 JS）。
- **成本增量**：≈0ms（同层数同面积，只换色值。估算）。
- **确定性**：**D3**（时段相关）——同 payload 跨时段两次出图颜色不同。连锁义务：①视觉回归必须钉住档位；②P2 渲染缓存 digest 必须纳入档位键（60s TTL 内跨档概率极低但语义必须正确）；③与 E01 的 digest 相位共用剥离规则。
- **风险**：中（系统性）。①品牌一致性：守岸人本命色被时段稀释的观感风险 → 幅度硬上限 5% 且只动明度/比例；②「不可预期感」是特性还是缺陷需用户裁决；③调度用系统本地时区（台账 #6 已知口径）使「深夜」在异时区机器偏移。
- **适用卡型**：全卡族。
- **契约影响**：零（token 值仍由 `derive_wash_tokens` 单一来源派生，兜底字面量不变）。

### E09 玻璃顶部内弧光——待裁（契约解读先行）

- **视觉效果**：每块 `mica-surface` 面板顶部一条白色内弧光（radial-gradient，alpha 0.10–0.16，高度 30–40%），液态玻璃的「顶光」物理暗示，立体感小幅提升。
- **实现思路**：面板 `::before` 静态渐变（现 `::before` 空闲的面板才可加；已被竖条/marker 占用的用包一层实现）。
- **形态**：CSS-only 静态。
- **成本增量**：+3–15ms（每面板一层渐变，单卡 3–8 面板。估算）。
- **确定性**：**D0**。
- **风险**：中（主要是契约解释面）。铁律 6 把「内高光语言」指派给 1px 渐变描边并明令禁止表外 box-shadow 内高光；`::before` 渐变弧光是描边语言的**延伸还是越界**，软文档未裁决 → 实施前必须在 `docs/rendering-contract.md` 补一条裁决（渐变高光带：白系、alpha≥0.05、≤0.16、只允许顶缘）。
- **适用卡型**：全部含 `mica-surface` 的模板。
- **契约影响**：测试面为零（非 box-shadow），软文档需补裁决条款。

### E10 卡片入场微动效——否决（本题要求的冻结帧分析）

- **设想**：面板淡入 + 上浮 8px、标题引言框先落、瓦片 stagger 进场，600–800ms 一击性动画 + `animation-fill-mode: both`。
- **冻结帧分析（核心）**：截图时机对照四档 wait（管线规格 §1.2）——
  - 3000ms 档（解析/占卜/菜谱族）：动画必已完结，截到终帧 ✓ 无鬼影；
  - 1500ms 档（media 兜底）：大概率终帧，边缘竞态；
  - **300ms 档（song_candidates）与 0ms 档（market/fx/stocks/affinity/usage/echo，networkidle 后即截，典型 500–1600ms 弹性）**：高概率**截在动画中段** → 半透明面板鬼影帧出卡，比糊图更难看且不可复现定位。
  - 「设计冻结帧」的解法只剩：让动画在**最早可能截帧时刻之前**必然完结（≤300ms）——但那等于动画几乎永远不被看见，而产出是静态 PNG，用户本来就看不见动画。**冻结帧不吃掉动画价值，是静态媒介根本没有动画价值**；所谓「入场动效的终帧」就是一张普通静态设计，直接把终态做成静态样式（现状已是）即可，动画本体只剩鬼影风险与栅格化开销。
  - P0 信号驱动落地后风险加重：双 rAF/字体/图片信号不含「动画完结」，截帧时机还会提前。
- **裁决**：**否决，不实施**。若未来出现 APNG/GIF 出图通道再重新评审；在此之前任何「会动」的诉求一律转译为「定格构图」诉求（见 E02/E05/E07 静版）。

### E11 数据数字滚动占位——否决（静态媒介 + 数据完整性）

- **设想**：metric-value 从 0 滚动/翻牌到目标值（需 JS 或 CSS 计数技巧）。
- **分析**：①静态 PNG 下用户只见一帧——滚动要么被截在**中间值**（4.9万 显示成 2.3万 = **错误数据上卡**，属数据完整性事故，比鬼影严重一个量级），要么截在终值（= 动画毫无痕迹）；②「占位」语义（加载骨架）在渲染管线无意义：HTML 构建 <5ms（F1），无异步数据阶段可占位；③需 JS，违背页面零 JS 现状。
- **裁决**：**否决，不实施**。数字层的真实提升走 E03（tabular-nums 等宽排版 + 行高收口），零风险拿到「数字精致感」。

## 4. 推荐首批实施（3 项）与理由

1. **E01 漂移相位策展**——零成本零契约风险，把全部卡片从 D2 升 D1，是视觉回归像素化与后续一切动版特效的确定性地基，且与 Track 2 渲染缓存 digest 语义同源共振。
2. **E02 星尘上升定格**——全目录最高用户可感惊艳度，静态 D0 无鬼影面，scoped 到好感/占卜/成就高情绪时刻，契合星空紫品牌资产，无 keyframes 扩展。
3. **E03 字体层级微雕**——近乎零成本零风险的全模板质感收口（等宽数字/字距/行高/balance），一次性抬升所有卡型的「印刷感」下限。

三项互不重叠（bridge 通道 / 定格构图 / 文本排版），可独立回滚、独立验收。
