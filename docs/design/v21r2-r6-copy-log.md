## 二、改前 → 改后对照（场景级）

### 晚报（用户点名实例）

**改前**：`今天辛苦了。睡前对一下账：`＋`收件箱今天没有新进的。`（生硬、AI 味）
**改后**（7 开场 × 6 空账行，确定性轮换，实跑样例）：
- `今天辛苦了。守岸人把这一天的账理了理，睡前看两眼就好。`＋`收件箱今天很安静，没有新记下的事。`
- `忙完就早点歇着。守岸人把今天记下的事拢了一遍，放在下面了。`＋`今天没有人往收件箱里放事情，它也歇了一天。`
- `晚上好。一天到头了，守岸人替你把小事都记着呢。`＋`守岸人看过了，收件箱今天零新增。`

有账行（6 变体，均保留条数信息）：`收件箱今天进了 {n} 条，都归好档了。` / `今天记下的 {n} 条，守岸人都替你收好了。` / `{n} 条新的进了收件箱，已经放进归档里了。` / `守岸人把今天进来的 {n} 条都理好了，归了档。` / `收件箱今天添了 {n} 条，都放得妥妥的。` / `今天攒下 {n} 条，守岸人已经替你理进档案了。`

想法池尾语（6 变体）：`有空的时候，挑一条让它转正？` 等（旧：`有空的时候挑一条变正经任务？`，单句）。

### 早报

- 空态（6 变体）：`早。收件箱和清单都干干净净的，今天轻装上阵。` / `早上好。守岸人看过了，没有攒着的事，也没有挂着的事，安心过今天。` 等（旧：单句钉死）。
- 有内容开场（6 变体，均以冒号引出列表）：`早。守岸人把今天要注意的理出来了：` 等（旧：`早。今天要注意的有：`）。
- 想法池备注（6 变体）：`（想法池还有 {n} 条，守岸人先替你收着）` 等（旧：`（想法池还有 {n} 条，先不动）`）。

### 命令面（capabilities）

- 帮助（6 变体）：`收件箱的用法：发「收件箱 内容」就把事情记下了，早报守岸人会一并整理；发「收件箱」能看现在攒着的。` 等（旧 `_HELP_TEXT` 单句、自称「我」）。
- 查询空（6 变体）：`收件箱空着呢。想到什么，随时丢进来。` 等（旧：`收件箱现在是空的。攒着的事随时丢进来。`）。
- 查询列表（6 变体，保留条数+清单原文）：`守岸人替你记着 {n} 件：\n{listing}` 等。
- 速记确认（6 变体，保留落盘行原样回显）：`守岸人收好了：{line}…` / `这件事守岸人替你记着：{line}…丢不了。` 等（旧：`收进了：{line}…早报的时候我一并理给你。`——旧自称「我」已全部改为「守岸人」）。

## 三、轮换机制

`character/daily_assist.pick_variant(key, variants, **fields)`：全局游标 `_VARIANT_CURSORS` + `threading.Lock`，`(offset) % n` 按序循环（与 `capabilities/chat.py` `persona_failure_message` 五池机制同构，规模收小为全局游标、无 per-session 表）。用户内容只作 `str.format` 参数传入，不参与模板解析（大括号内容安全，有回归测试）。

## 四、语气守卫（tests/test_daily_assist.py，常驻回归）

- 11 个池 × 每池 ≥6 变体；
- 违禁词扫描：`～ / 系统 / 提示词 / 脚本 / 注入 / 作为AI / 值得注意的是 / 综上所述`；
- 第三人称自称：每池至少一处「守岸人」；早/晚报开场池**每条**必含（当日文案的声线锚）；
- 简报成品（含 LLM 段拼装后）过同一违禁词扫描；
- `pick_variant` 轮换确定性 + 各池游标独立 + 格式化安全。

## 七、口径冲突披露（诚实底线，待用户裁决）

`personas/shorekeeper/knowledge/守岸人_人格与表达规范.md:741` 写明守岸人日常以第一人称「我」自称、仅回望过往时切第三人称；本批任务指令明确要求「守岸人第三人称自称」并写入语气守卫。两处冲突，本席按优先级服从用户批次指令（第三人称自称已落地+守卫锁死），在此登记供用户后续裁定；若改回第一人称，只需换池内文本+放宽守卫断言，机制不动。库内先例 `chat.py` 五池失败话术亦用「我」（如「再发一次，这次我会把它写完」），与人格规范一致而与本批口径不一致，一并披露。
