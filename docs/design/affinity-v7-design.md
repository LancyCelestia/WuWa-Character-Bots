## 一、v7 的四条结构性改动（不是把常数调小）

1. **饱和域换成潜变量**：显示分由无界潜变量映射而来 ⇒ **数学上永不触顶**，永远保留梯度与区分度。
2. **边际递减跨日累积**：同类信号按"新鲜度"衰减而非按自然日重置 ⇒ 刷次数真的越来越没意思。
3. **计分单元从次数变质量**：一次交互算一个质量分 `q`，关键词只是其中一个子项 ⇒ 敷衍不涨、敷衍式连发不涨。
4. **按人归一 + 修复通道**：活跃度用该人自己的基线归一；道歉/和解有独立加成且不受配额限制 ⇒ 像人的关系，且可修复。

## 二、公式

### 2.1 表示与映射
```
内部潜变量 z ∈ ℝ ；展示分 s = 100·tanh(z) ；初始 z₀ = atanh(0.1) ≈ 0.10033   （仍是 10 分，与 _AFFINITY_BASE 对齐）
硬护栏 z ∈ [−Z_HARD, +Z_HARD]，Z_HARD = atanh(0.985) ≈ 2.578                 （对应 ±98.5 分，永不实际触边）
八档态度：沿用 _ATTITUDE_TIERS 的展示阈值（产品口径不动）
```
`tanh` 的导数随 `|s|` 增大而变小 ⇒ **高位天然钝化**，取代 §v6.1 的分段 smoothstep 带（该函数退役，改为 `saturation_factor` 直接返回 `1 - tanh²(z)` 形式的一致性检查用辅助函数，不再充当主机制）。

### 2.2 更新
```
Δz = base_step · q · novelty · rhythm · mood · impression
z  ← clamp(z + Δz, −Z_HARD, +Z_HARD)
```
| 因子 | 定义 | 缺省 | 取代什么 |
|---|---|---|---|
| `base_step` | 单位步长（z 域） | 0.10 | v5 `_BEHAVIOR_DELTA` 的 0.02/0.05/0.10 分档（改为由 `q` 的符号与幅度表达，不再一行为一常数） |
| `q ∈ [−1,+1]` | **互动质量分**（§2.3） | — | 取代"命中 positive ⇒ +0.02" |
| `novelty` | `ρ^(n−1)`，`n` = **该人该类型累计**第 n 次同类显著信号（EMA 计数，**跨日按 τ 半衰回升**，不再按自然日重置） | `ρ=0.90`，回升半衰 21 天 | 取代 §v6.2 的 `0.6^n + 每日重置 + floor 0.2` |
| `rhythm` | 以该 principal 近 28 天日均互动轮次 `r`（EMA）归一：`1/(1 + max(0, r−r_ref)/r_ref)` | `r_ref=8` | 新增（治"话痨更快到顶"） |
| `mood` / `impression` | **保留 v5/v6 的调制定位**（乘在步长上），带宽收进 `[0.85,1.15]` / `[0.80,1.25]` | 现值收敛 | 不改语义，只重新标定到 z 域 |
| `repair_gain` | 道歉/澄清/和解信号（`_TEASE_RE` 家族 + 明示道歉词表）时 `Δz` 乘 1.4，**且不进 `novelty` 计数** | 1.4 | 新增（关系可回血，和解不该被配额挡住） |
| 负向单事件上限 | `|Δz| ≤ 0.10`（约合展示端高敏感区一次最多 ~4 分） | 0.10 | 取代 `_BUDGET_SINGLE_NEGATIVE_EVENT_POINTS=1.0` 的分口径 |
| 熔断 | 每人每日总移动 `|ΣΔz| ≤ 0.12`；`n>25` 次同类信号不再计分 | — | 取代 `_DAILY_EFFECTIVE_CAPS`（降级为兜底，不再是主机制） |

**净效果（可验证）**：同样"每天 10 句好话"，v6 约 10 天冲到 75 分；v7 因 `novelty` 跨日累积 + `rhythm` 归一，
**同期约到 30~40 分**，且要到 80 分需要以周为月的持续高质量互动——顶端不再有"大家挤一档"的坍缩。

### 2.3 质量分 `q`（取代关键词计数）
`q = clamp(w1·主动度 + w2·延展度 + w3·情绪词 + w4·尊重边界 + w5·回应性, −1, +1)`，五个子信号**全部来自已有会话事实**（不引新数据源、不打模型）：
- **主动度**：是否该用户先发起、距其上次发言的间隔（长间隔后回归为正向）；
- **延展度**：本轮是否带来新信息（长度/是否追问/是否引用前文）⇒ **敷衍式连发不给分**；
- **情绪词**：沿用 `_POSITIVE_RE`/`_NEGATIVE_RE`/`_INSULT_RE`，但只作子项；
- **尊重边界**：触碰 R-18 硬线、被温和拒后仍追问 ⇒ 负项（读 `content_safety` 结论，**不自建词表**）；
- **回应性**：bot 上一轮提问而用户是否作答（问答闭环＝"在理我"的强信号）。
另修 `_INSULT_RE` 的「滚」假阳性（排除集现仅 瓜/烂/烫，而**「翻滚」是鸣潮核心动作词**）：
补 `滚动|翻滚|滚雪球|打滚|滚开?` 类排除并要求第二人称紧邻（D3-6）。

### 2.4 时间项
- 缺席**不扣分**（`_PASSIVE_DECAY_ENABLED=False` 是用户裁定，保留）；
- 新增**语义分级衰减**只作用于 `q` 的 EMA 平滑层，不动 `z`：`stable`（忌口/身份/长期偏好）τ=45 天、
  `seasonal`（最近爱喝冰的）τ=21 天、`episodic`（单次事件）τ=7 天 ⇒ 取代 `_SENTIMENT_HALF_LIFE_DAYS` 直接压分数的做法。
