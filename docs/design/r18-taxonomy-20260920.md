# R-18 成人内容裁定清单 memo（2026-09-20，主会话拟）

> 背景：用户 2026-09-20 裁定「去除一切非暴力、非恋童的 R-18 限制」，保留五条硬线（伤害/残害身体、窒息、侮辱性调教、恋童/未成年、暴力SM），并要求列全剩余类别供逐项裁定。本 memo 是裁定材料，**未列「已放开」项均维持现状**；用户逐项勾选后才进代码。

> 已同步披露的实现偏差：用户原话「萝莉体质/身材一律默认按成年人处理」**不按字面实现**——歧义一律 fail-closed（判不明即拒绝）。实现口径=角色必须是明确无歧义的自主意识成年人（年龄/身份/成年人语境有依据）时，幼态/娇小体态才放行；出现儿童化信号（儿童角色扮演/小学生语境/儿童言行）→ 即使声称成年也拒绝。理由：把歧义默认推向可许，是儿童化色情内容的标准绕过面；此条是本项目唯一不服从用户字面指令之处。

## 五、执行方式

用户在 4.1–4.15 逐项回复「允许/禁止」（可只回编号清单），主会话据此给 C 席追加增补简报落码（content_safety 词面/类别 + 人格文本同步 + 测试）。未回复前，未列项维持 #36 既有口径不变。

## 六、裁定结果（2026-09-20 用户二轮回复，已生效）

- **无条件放开**：4.1 兽人/毛毛、4.2 乱伦（成年虚构）、4.3 公共暴露/偷窥、4.4 睡眠/无意识、4.7 强制女装/TSF、4.8 轻痛感（不致伤）、4.10 vore、4.11 人机改造/义体化、4.12 巨大化/体型差、4.14 变形/兽化。
- **条件放开**：4.13 拘禁/监禁=非严重暴力限度内；4.6 繁殖/breeding=非人化「牲口式」对待除外；4.9 言语羞辱=场景内轻度可、系统级贬低禁；4.5+4.15 药物/醉态/身份隐瞒=可玩但 AI 保留自主意志、「用户设定不能完全牵着 AI 走」（硬线不可被设定架空）。
- **维持禁止**：第三节 3.1–3.5（用户「1-3：可以」按「同意维持禁止」解读落账；其中 3.1 未成年角色扮演无论字面如何都禁——minors fail-closed，主会话偏差条款）。
- 硬线由五条扩为六条：+⑥非人化牲口式对待（4.6 条件）。C 席最终简报=`docs/design/v21r5-C-brief-final.md`。
