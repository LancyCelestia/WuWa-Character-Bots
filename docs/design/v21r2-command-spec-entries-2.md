- 九形态：EN全=news(既有)｜EN简=—｜EN语=daily news(建议,未占用)｜简中=快报/今日快报/今日热点(既有全族)｜繁中=快報/財經快報/國際新聞 等(既有全族)｜中简=—｜拼全=kuaibao(既有)/jinrikuaibao(既有)｜拼首=kb(既有)/jrkb(既有)｜组合=类目词×新闻|快报 组合形态(既有)
- 权限：全员
- 参数：| 类目词 | 枚举 | 否 | 财经→finance、国际→world、科技/AI/人工智能→tech、其余→mix 轮转 | 无=mix 轮转 | 圈定栏目 |

- 示例：快报｜科技新闻｜财经快报｜/bot 资讯 快报 国际
