## C8 到点吃什么开场（6 → 21）

正身：根 `plugins/bot_unified_runtime/__init__.py:3299-3306`（`_MEAL_OPENERS`），取句 `_build_meal_push_text()` →
`pick_variant("meal_open", …, name=…, suffix=…)`。

**开工前核实的结构性约束（写手必须守，违者实现期必红）**：
1. **每条必须以 `{name}{suffix}` 收尾且末尾不加任何标点**——`tests/test_v21r2_hotzone_meal_variants.py::test_meal_push_text_keeps_name_and_suffix_intact`
