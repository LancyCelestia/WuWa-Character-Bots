## 第 3 步：实施

### 3.1 算法真身改动（`character/affinity.py`）

1. **边际递减**：新纯函数 `v8_marginal_gain(z, half_z) = half/(half+|z|)`，
   γ∈(0,1]、只依赖 |z|（正负严格对称）、随 |z| 严格递减、|z|=half 处恰半额。
   half 取在册 `z_hard`（=atanh(z_hard_bound)，缺省 atanh(0.985)≈2.443）——
   旧"±98.5 硬界"点改为**半衰减参考点**，经既有键 `bot_affinity_z_hard_bound`
   可调，未新增配置键。消毒：脏 z 按 0（γ=1）；half≤0 ⇒ γ≡1（退化 v7 原形，
   不抛不冻结）。
2. **接入点**：`_v7_delta` 两分支（override / 普通计分）汇流后、滚动额度护栏
   **之前**：`raw *= v8_marginal_gain(z, v7.z_hard)`。放在帽后 ⇒ 单事件上界
   从 0.10z 收紧为 0.10×γ(z)≤0.10z——**两道护栏在任何高度仍是上界、只收紧
   不放宽**，红线"禁止瞬间剧烈加/减"逐点保持。
3. **长尾**：更新处原 `max(-z_hard, min(z_hard, z+applied))` 截断删除，改为
   浮点表示域护栏 `_V8_Z_REPR_DOMAIN = atanh(0.999999) ≈ 7.254`——展示分
   严格落在 (−99.9999, +99.9999)：可越过旧 ±98.5 参考点继续减速上行/下行
   （永不冻结），但结构上永不触顶；8 档态度表判定不受影响（|s|>97 早已是最
   高/最低档域）。
4. **零迁移**：惰性映射 `z = atanh(clamp(score/100, ±0.985))` 一字未动；
   `v7_raw_delta_z` 纯函数体一字未动（在册锁保持）；`_observe` 读回路径未动。
   没有任何存量用户被重置——新增守恒锁 `test_v8_lazy_migration_still_
   conserves_every_legacy_row`（14 行样本逐点复证 + 二次读回幂等）。
5. 文档面：模块头、常量注释、`V7Settings.z_hard` 属性、`_v7_delta` docstring
   同步 v8 语义（硬界→半衰减参考点；新增表示域护栏条目）。
   `capabilities/affinity.py` 算法说明**未改**：现文案已是定性口径
   （"边际递减""没有固定加几减几"），与 2026-09-12 裁定一致且无需数字；
   `affinity_replay.py` 只重放既记 delta 账、不重算 z 式，无需同步。
