# 解析信息卡验收标准（Standard）

> 版本：2026-09-01（后端字段核对 + 卡片渲染元素核对完成）
> 适用范围：`bot.content` 解析信息卡（链接 → 卡片 + 文本）。只验收后端数据与卡片呈现；卡片 HTML/CSS 属前端，不在本周期改动范围。
> 配套实现：`docs/handover-2026-09-01.md`；字段核对明细见 `findings.md`。

## 〇、总则（所有字段通用）

1. **权威数据**只来自平台公开页面/接口；拿不到保持 `None` 并在 `provenance.limitations` 说明，**不伪造、不用 0 冒充未知**。
2. 文本输出与卡片渲染都只消费嵌套模型（`identity/content/creator/engagement/media/music/provenance`），不读扁平字段。
3. **签名保链接**：博主签名里的自写跨平台链接（如 "IG: xxx"、"YouTube: xxx"）原样保留；截断必须保住链接（`_truncate_keep_links`）。
4. 失败降级：解析失败/登录墙/风控 → 诚实文案 + 原链接，不中断。

## 一、博主信息标准（11 项）

| # | 字段 | 模型落点 | 卡片呈现 | 真机验收点 |
|---|---|---|---|---|
| 1 | 头像 | `creator.avatar_url` | 作者区头像（author 区块） | 头像能加载、非默认图 |
| 2 | 昵称 | `creator.name` | 作者名 | 与平台页一致 |
| 3 | UID（全站唯一标识/自定义标识符） | `creator.platform_creator_id`（数字 ID）／`creator.handle`（@自定义） | 作者区 ID/Handle 行 | 点击可回跳个人主页 |
| 4 | 签名 | `creator.signature`（或 bio） | 作者区签名 | 原文完整；自写链接可见可点 |
| 5 | 注册日期 | `creator.joined_at` | 作者区"加入时间"（YYYY-MM-DD） | 后端：B站/小红书/Pixiv/Telegram 不公开；YouTube/微博/X 可得。**呈现限制：加入时间行仅旧卡分支渲染，Mica 卡暂不显示该行**（前端模板现状，不判失败） |
| 6 | 粉丝量 | `creator.follower_count` | 作者统计行"粉丝" | 数字与平台一致（万级换算正确） |
| 7 | 关注数 | `creator.following_count` | 作者统计行"关注" | 同上 |
| 8 | 视频数 | `creator.video_count` | 作者统计行"视频" | 平台无此概念则隐藏 |
| 9 | 专栏数 | `creator.platform_extra["column_count"]` | 作者统计行"专栏"（B站） | 仅 B站有；其余隐藏 |
| 10 | 长视频数 | `creator.long_video_count` | 作者统计行（暂未呈现） | 当前无平台提供，标注 limitation |
| 11 | 帖子/笔记数 | `creator.post_count` | 作者统计行"帖子/笔记" | 与平台一致 |
| — | 作品发布时间 | `content.published_at` | 卡片时间戳/文本【发布】 | 与平台页面时间一致（本地时区换算正确） |

## 二、媒体信息标准

| # | 字段 | 模型落点 | 卡片呈现 | 真机验收点 |
|---|---|---|---|---|
| 1 | 标题 | `content.title` | 卡片标题区 | 与平台一致（截断带省略号） |
| 2 | 封面 | `media` 首张图片 / `content.platform_extra["cover_url"]` | 封面大图（Banner） | 原图加载、非防盗链裂图 |
| 3 | 简介 | `content.summary`（博主原文）/ `content.body`（正文） | 简介区 | 原文保留、元数据行不混入 |
| 4 | 数据 | `engagement.*` | 指标栏（播放/点赞/弹幕/评论/投币/收藏/分享/转发…） | 各项数值与平台一致；未知隐藏不填 0 |

## 三、页面元素标准（卡片渲染层）

| # | 元素 | 实现 | 真机验收点 |
|---|---|---|---|
| 1 | 平台 Logo（右上角品牌块/页脚） | `PLATFORM_LOGO_FILES` SVG；**缺 SVG 的平台用文字兜底**；**品牌 Logo 块仅 Mica 卡分支渲染，旧卡分支（微博单条/Pixiv 插画/B站空间/小红书主页等）无品牌块**（前端模板现状） | B站/小红书/微博/油管/推特的 Mica 卡显示 Logo；Telegram/Pixiv 文字兜底；旧卡分支不判失败 |
| 2 | 网页 URL 二维码 | bridge 对 `canonical_url` 生成 QR（qrcode 依赖缺失或 URL 为空时隐藏） | 二维码可扫出原链接；无 URL 时无二维码属预期 |
| 3 | 弹幕数量 | B站 `danmaku_count`（指标栏"弹幕"） | 仅 B站视频卡有；其他平台无此概念 |
| 4 | 左下角品牌 Logo | 同 #1（右上角 brand block） | 与平台配色一致（Mica 派生，不写死品牌色） |
| 5 | 右下角页脚 | 平台名/Logo + 机器人头像/名字 + "Shorekeeper Parser" | 平台名正确；机器人元素见 §四 |

## 四、机器人信息标准

| # | 字段 | 实现 | 验收点 |
|---|---|---|---|
| 1 | 头像 | `bot_avatar_url`（config `bot_persona_avatar_url` → 运行时 `_resolve_bot_avatar_url`） | 页脚机器人头像显示 |
| 2 | ID | **不进入卡片**（内部标识 `self_id`，属运维数据） | 无 ID 显示属预期 |
| 3 | 英文名 | 页脚 `bot_name`（config `bot_persona_display_name`，默认"守岸人"） | 与配置一致 |
| 4 | 解析器英文名 | 页脚固定文案 "Shorekeeper Parser" | 恒显示 |

## 五、跨平台关联标准

- 博主在其他平台的自写账号链接（个人签名/简介原文中的 URL）**原样进入 `creator.signature` 并在卡片签名区展示**（签名本身默认不截断）。
- 仅**文本摘要截断场景**走 `_truncate_keep_links` 保链接：B站空间签名 200 / 微博主页简介 300 / 油管频道简介 300；截断点恰在 URL 中间时回退到链接起点并追加完整链接。
- 平台侧说明：X/小红书/微博单条/B站视频卡的作者签名均不截断。

## 七、已知缺口与诚实处理（验收时按此判定）

| 缺口 | 判定标准 |
|---|---|
| Telegram/Pixiv 无平台 Logo SVG | **可接受**：页脚/品牌块用文字兜底（`platform_footer_label`），不得因此判失败 |
| X 单链接无数字 UID / 收藏数 | 标注 limitation，卡片隐藏对应行；订阅链路才有 |
| B站/小红书/Pixiv/Telegram 无注册日期 | 平台不公开或接口无 → 作者区"加入时间"整行隐藏 |
| 长视频数全平台不可得 | 所有平台 limitation，作者区无此行 |
| 小红书粉丝/关注仅在主页解析可得 | 笔记页卡不显示粉丝/关注属预期 |
| Pixiv 作者签名不可得 | 插画 ajax 无简介；作者页解析才有 |
| 机器人 ID 不显示 | 属预期（内部标识不进卡片） |

### 通用必核点（每张卡都查）

1. **机器人信息**：页脚机器人头像显示（与配置一致）；机器人名字（`bot_persona_display_name`，默认"守岸人"）；页脚恒有 "Shorekeeper Parser" 英文名；**页脚不显示机器人 ID 属预期**（内部标识）。
2. **跨平台关联**：若博主签名/简介自带其他平台链接（"IG: xxx"、"YouTube: xxx" 等），签名区原样可见；文本摘要被截断时链接仍在。
3. **页面元素**：Mica 卡右上角平台品牌块（B站/小红书/微博/油管/推特为 Logo，Telegram/Pixiv 为文字兜底）；二维码可扫出原链接（无 URL 时无码属预期）；B站视频卡指标栏含"弹幕"；右下角页脚平台名与平台一致。
4. **文本输出**：【标题】【作者】【数据】【发布】【简介】【链接】分区完整；数据行无"时长/发布时间/AV号"等内部字段泄漏。
5. **降级**：登录墙/风控平台（X/小红书无 Cookie 时）显示诚实文案 + 原链接，不崩溃。

每项通过条件：卡片出现对应元素且数值与平台页面核对一致；不可得项按 §七 判定；全程无崩溃、无内部字段泄漏、无密钥。
